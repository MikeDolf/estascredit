# Использованные ключевые слова

> Основные ключевые слова, уже задействованные на сайте.
> **Правило:** прежде чем выбрать основной ключ для новой страницы, свериться с этим файлом. Никогда не использовать один и тот же primary дважды — это ведёт к каннибализации.

---

## Правило выбора ключевых слов

При сборе кластера для новой страницы:

1. **Primary берётся из CSV с ключевыми словами по спецтехнике** (актуальный экспорт исследования ключевых слов для ниши вилочных погрузчиков / спецтехники). Никогда не придумывать primary.
2. **Сначала свериться с этим файлом** — не повторять primary.
3. **Вторичные / кластерные ключи: сначала CSV, придумывать только то, чего не хватает.**
   - Просмотреть CSV на вариации с тем же интентом, что и primary.
   - Если в CSV есть подходящие вторичные — использовать их (пометить ✓ CSV).
   - Если подходящих нет — придумать 4–5 на основе типичных «люди также спрашивают» / связанных запросов (пометить `(придумано)`).
4. **Тест на совпадение интента:** захочет ли человек, ищущий эту фразу, попасть на ту же страницу, что и человек, ищущий primary? Если нет — это другой кластер.

## Активные primary

*Список пуст — CSV с ключевыми словами по нише спецтехники/вилочных погрузчиков ещё не добавлен в проект. Перед первым постом собрать исследование ключевых слов и завести первую запись здесь по образцу ниже.*

### Шаблон записи

```
### N. `primary-ключ` → /путь-страницы

- **Источник primary:** ✓ CSV (объём X, KD Y) или `(придумано)` — избегать, если возможно
- **Использован на странице:** `/путь/`
- **Кластер:**

| Вторичный ключ | Источник |
|-----------------|----------|
| ... | ✓ CSV / `(придумано)` |
```

---

## Порядок действий для следующего поста

1. Открыть актуальный CSV с ключевыми словами по спецтехнике
2. Отсортировать по объёму × (1 / KD) или похожей метрике
3. Пропустить любой primary, уже числящийся выше
4. Выбрать primary из CSV, который ещё не использован
5. Найти в CSV вторичные ключи с тем же интентом — использовать их первыми (пометить ✓ CSV)
6. Заполнить оставшиеся слоты кластера придуманными ключами (пометить `(придумано)`)
7. Добавить новую запись в этот файл **до** написания поста
8. Опубликовать пост, обновить «Использован на странице»
