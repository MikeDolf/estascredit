# estascredit.ru

> **Статус: каркас после смены направления.** Сайт раньше продавал прямые
> поставки спецтехники и автомобилей из Китая. Сейчас переделывается под
> технику, уже имеющуюся в наличии в Свердловской области — весь прежний
> контент (Китай, растаможка, 16 гео-страниц, 11 статей, генератор сетки
> `_build`) удалён. Осталась только разметка: секции пустые, ищите
> `<!-- TODO: ... -->` в `index.html` и `articles/index.html`.

Статический сайт на чистом HTML/CSS/JS, без сборки и зависимостей. Деплоится
через GitHub Pages на домен **estascredit.ru**.

## Структура репозитория

```
index.html                              — главная (лендинг), сейчас пустой каркас
articles/index.html                     — список статей, сейчас без статей
assets/css/style.css                    — общие стили для всех страниц
assets/js/main.js                       — общий JS (меню, FAQ-аккордеон, форма заявки)
_relay/worker.js                        — Cloudflare Worker: приём формы заявки, отправка в MAX
_checks/check_site.py                   — статические проверки перед коммитом
CNAME                                   — домен для GitHub Pages
robots.txt, sitemap.xml                 — базовая SEO-разметка
```

Каждая HTML-страница самодостаточна: подключает `assets/css/style.css` и
`assets/js/main.js` по относительному пути и не требует сборки — можно
открыть файл прямо в браузере.

## Как добавить статью

Шаблона статьи сейчас нет (все были про импорт из Китая и удалены вместе с
бизнес-моделью). Порядок действий, когда появится первая статья под новую
тематику:

1. Создайте `articles/<slug>.html` — латиницей, через дефис, без пробелов.
   Возьмите за основу структуру `index.html` (`<header>`/`<footer>`, подключение
   `../assets/css/style.css` и `../assets/js/main.js`) и оформите текст статьи
   классом `.article-body` (стили для `h2`/`h3`, списков, `blockquote`, таблиц
   уже готовы в `assets/css/style.css`).
2. Добавьте карточку в `articles/index.html` (блок `.articles-grid`).
3. Добавьте новый `<url>` в `sitemap.xml`.
4. Закоммитьте и запушьте — правки на GitHub Pages появляются через
   1–2 минуты после пуша в основную ветку.

## Проверки перед коммитом

```
python3 _checks/check_site.py
```

Проверяет по всем HTML-страницам: битые внутренние ссылки и якоря,
валидность JSON-LD, дубли `title`/`description`, `<img>` без `alt`,
опечатки (пропущенный пробел после запятой, повтор слова, непарные кавычки),
заглушки в публикации, запретные фразы-противоречия и совпадение
«один анкор → один URL» (защита от каннибализации запросов).

Возвращает код 1 при любом нарушении. **Сейчас скрипт красный намеренно** —
пока в разметке пустые секции и `<!-- TODO: ... -->` комментарии, это
ожидаемо. Заполняйте контент и перепроверяйте по ходу работы.

Списки `FORBIDDEN_PHRASES` (противоречия условиям работы) и
`ARITHMETIC_RULES` (проверка числовых утверждений) в `_checks/check_site.py`
заполняются по фактуре нового бизнеса — пока пустые.

## Что нужно заполнить

Ищите комментарии `<!-- TODO: ... -->` в `index.html` и `articles/index.html`.
Коротко, что отсутствует:

- Название компании, слоган, логотип (сейчас пустые — прежнее название
  «СИНОТЕХ» относилось к импорту из Китая и здесь больше не используется)
- Заголовок, УТП и цифры в hero-блоке
- Категории техники и позиции «в наличии» — вероятно другой набор, чем был
  раньше (тогда: экскаваторы/погрузчики/самосвалы/автокраны/легковые авто под

  заводе → растаможка → доставка; для техники в наличии процесс другой)
- Преимущества компании
- FAQ (было 5 вопросов про импорт/лизинг/растаможку — все удалены)
- Список опций в форме заявки (`<select id="f-type">`) — сейчас всё ещё от
  старого каталога
- Контакты в подвале, страницы политики конфиденциальности и оферты

## Настройка GitHub Pages (сделать один раз вручную)

Через API репозитория Pages включить нельзя, поэтому это единственный шаг,
который нужно сделать руками в интерфейсе GitHub:

1. Слить ветку с сайтом в `main` (или сделать `main` рабочей веткой).
2. **Settings → Pages**.
3. **Source**: Deploy from a branch.
4. **Branch**: `main`, папка `/ (root)` → **Save**.
5. В поле **Custom domain** появится `estascredit.ru` (подхватится из файла
   `CNAME`) — подтвердите и дождитесь проверки DNS.
6. Включите **Enforce HTTPS**, как только сертификат будет выпущен
   (обычно несколько минут после проверки DNS).
